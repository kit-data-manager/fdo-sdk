# FDO SDK

## Local Development
Requirements:
- node.js (>= 24)
- corepack (ships with node.js)

Initial setup:
```bash
# automatically installs the pnpm package manager
corepack install
corepack enable
# install dependencies
pnpm install
```

## Packages
| Name       | Description                                                    |
|------------|----------------------------------------------------------------|
| primitives | Contains primitives for records and graphs                     |
| examples   | Contains examples for using the primitives package             |
| docs       | Contains documentation for the primitives and mapping packages |
