TypeScript · FAIR Digital Objects

Create, publish and resolve FDO records.

The FDO SDK models records as sets of PID-identified attributes, maps source data to records continuously, and keeps the PIDs of records that still exist stable across runs.

Open the playground Browse the API

Records and profiles

Build records from PID-identified attributes, apply profiles that map readable names to PIDs, and link records with unidirectional or bidirectional references.

Continuous mapping

Describe a mapping as a pure function of your source data. Every run produces the records to create, update and delete against the previously published graph.

Bring your own backend

Publishing and resolving are interfaces. Use the in-memory testing backend for local experiments, or implement the adapters for your infrastructure.
