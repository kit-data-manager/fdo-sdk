FDO SDK

A TypeScript SDK for FAIR Digital Objects.

Internal testing — not ready for use

This SDK is under active development. Its API may change, and it should not be used in production.

The FDO SDK provides tools for creating, publishing and resolving FDO records. It models records as sets of PID-identified attributes, supports profiles and references between records, and can map source data to FDO records continuously while keeping published PIDs stable.

  • Documentation — the generated API reference for the SDK packages.
  • Playground — run and edit the examples in the browser.
  • Source code — the repository and issue tracker.

FDO SDK is open source under the Apache-2.0 license.
