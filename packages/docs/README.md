# @fdo-sdk/docs

The generated API reference for the SDK. It documents the public API of
`@fdo-sdk/primitives`, `@fdo-sdk/mapping` and `@fdo-sdk/simple-types` as one
TypeDoc project, so types that cross package boundaries are linked.

It is a repository-internal package that exists to build and serve the
documentation.

## Commands

```bash
pnpm --filter @fdo-sdk/docs build      # HTML + Markdown
pnpm --filter @fdo-sdk/docs generate   # HTML only
pnpm --filter @fdo-sdk/docs build:markdown
pnpm --filter @fdo-sdk/docs serve      # serve generated/ locally
```

Outputs:

- `generated/` — the HTML site (gitignored)
- `generated-md/` — the same reference as Markdown (gitignored)

Both are regenerated by `pnpm build` from the repository root.

## Deployment

`packages/docs/landing/` contains the static landing page that becomes the
root of the published site. `pnpm build:pages` from the repository root builds
all packages and assembles the GitHub Pages artifact in `site/`:

```
site/              landing page
site/api/          TypeDoc HTML (from generated/)
site/playground/   playground build (from packages/playground/dist)
```

The `Deploy documentation and playground` workflow publishes that artifact on
every push to `main`. The repository's Pages source must be set to
**GitHub Actions** once under **Settings → Pages**.

## Layout

| File                    | Purpose                                                      |
| ----------------------- | ------------------------------------------------------------ |
| `src/primitives.ts`     | Re-exports `@fdo-sdk/primitives` as a documentation module   |
| `src/mapping.ts`        | Re-exports `@fdo-sdk/mapping`                                |
| `src/simple-types.ts`   | Re-exports `@fdo-sdk/simple-types`                           |
| `landing/`              | Static landing page published at the root of the Pages site  |
| `typedoc.json`          | HTML configuration and entry points                          |
| `typedoc.markdown.json` | Markdown configuration                                       |
| `tsconfig.json`         | Maps `@fdo-sdk/*` to package sources for cross-package links |

Because `tsconfig.json` points at the package sources, TypeDoc can document
and link types across packages without a prior build.

## Adding another package

1. Add `src/<package>.ts` with `export * from "@fdo-sdk/<package>"`.
2. Add the entry point to `typedoc.json` and `typedoc.markdown.json`.
3. Add a `paths` mapping in `tsconfig.json`.
4. Add the package to `devDependencies`.
